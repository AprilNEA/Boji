训练、饮水、睡眠和身体记录只保存在你的设备上，不会上传。账号和会员卡由俱乐部服务保存。完整的处理规则见[隐私政策](/privacy/)。

## 数据保存在哪里

| 数据 | 保存位置 |
| --- | --- |
| 训练、饮水、睡眠、体重、腰围 | 你的设备 |
| 读取到的健康数据 | 只在 App 运行时显示，不保存 |
| 账号、会员卡 | 俱乐部服务器 |
| 本机的登录状态、会员卡缓存 | 你的设备 |

卸载 App 会删除本机的记录。卸载前，先导出需要保留的记录。

## 导出记录

<ShotWithText name="app:settings" alt="设置页：我的信息、俱乐部账号、Apple 健康、小组件与 Apple Watch 等分组" caption="设置">

<Steps>
  <Step>
    打开「设置」>「隐私与数据」。
  </Step>
  <Step>
    点「导出我的数据」。
  </Step>
  <Step>
    选择保存位置。
  </Step>
</Steps>

</ShotWithText>

App 把本机记录保存为一个 JSON 文件，文件名为 `boji-records`。文件包含训练场景、每天的饮水量、睡眠时长、完成的课程，以及全部体重和腰围记录。文件不包含登录信息、会员卡缓存和健康数据。

导出文件的内容类似下面这样：

```json title="boji-records.json（节选）"
{
  "selectedPlan": "home",
  "records": [
    {
      "date": "2026-10-23T00:00:00Z",
      "waterML": 750,
      "sleepHours": 7.5,
      "completedWorkoutIDs": ["mobility"],
      "minutes": 10
    }
  ],
  "bodyEntries": [
    { "date": "2026-10-23T08:00:00Z", "weight": 70, "waist": 80 }
  ]
}
```

<Callout type="warn">
导出文件包含身体数据，妥善保管，不要公开发送。App 目前不能导入这个文件。
</Callout>

## 换到新手机

App 目前没有云同步，也不能导入导出文件。

- **iPhone**：用 iCloud 云备份或电脑备份恢复新设备时，备份可能包含薄肌的本机记录。登录状态不会迁移，在新设备上重新登录即可。
- **Android**：系统备份和设备迁移不包含薄肌的记录。

## 删除本机数据

<Steps>
  <Step>
    打开「设置」>「隐私与数据」。
  </Step>
  <Step>
    点「删除全部本地数据」并确认。
  </Step>
</Steps>

<Callout type="error" title="无法撤销">
App 会删除本机的全部记录和训练场景，清除本机的登录状态和会员卡缓存，关闭共享，并断开健康数据。这项操作无法撤销。
</Callout>

在 iOS 上，如果薄肌有写入 Apple 健康的权限，你还可以选择是否同时删除薄肌写入 Apple 健康的数据。

删除本机数据不会删除服务器上的账号。删除账号的方法见[账号](/docs/guide/account/#删除账号)。

## 共享给小组件和手表的数据

开启「共享当天打卡状态」后，小组件和手表只收到三项是否已记录和训练场景，不收到具体数值、健康数据或会员信息。详见[小组件与手表](/docs/guide/widgets-and-watch/)。
