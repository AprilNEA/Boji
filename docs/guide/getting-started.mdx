打开 App 后选择一个训练场景，就可以开始记录。使用 App 不需要注册账号，也不需要授予任何权限。

## 选择训练场景

第一次打开 App 时，欢迎页会问「你想在哪里开始？」。

<Screenshot name="welcome" alt="欢迎页：选择居家训练或健身房训练，下方是开始我的计划按钮" caption="欢迎页" />

选择一个场景，然后点「开始我的计划」：

- **居家训练**：徒手开始，循序渐进。这是默认选项。
- **健身房训练**：器械入门，专注动作。

训练场景决定今天页和训练页推荐哪套课程。所有课程始终都可以选择，场景不会隐藏任何课程。

之后可以随时更换场景：

- 在训练页顶部切换「训练场景」。
- 在「设置」>「我的信息」中修改「训练场景」。

## 认识四个页面

App 底部有四个页面，在 iPad 上显示为侧边栏。

| 页面 | 用途 |
| --- | --- |
| 今天 | 查看当天的训练、饮水和睡眠是否已记录，记录饮水和睡眠，打开今日推荐课程 |
| 训练 | 浏览 14 套课程，查看动作说明，开始跟练 |
| 足迹 | 查看累计训练、最近一周和体重、腰围趋势 |
| 俱乐部 | 领取会员卡，参加每周本地挑战，阅读入门手册 |

每个页面右上角都有「设置」按钮。

## 一天怎样计算

App 按设备的本地日期计算一天，从 0:00 开始。新的一天开始后，今天页的记录状态会重置。所有记录都计入当天，不能补记或修改以前的日期。

## 外观和语言

在「设置」>「外观」中选择「显示模式」：「跟随系统」「浅色」或「深色」。

App 没有单独的语言设置，界面语言跟随系统。在 iPhone 上，你也可以在系统「设置」>「薄肌」>「语言」中为 App 单独选择语言。
