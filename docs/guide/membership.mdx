薄肌会员卡是免费的俱乐部身份卡。领卡没有身材门槛，不需要身体照片或体脂数据，也没有支付步骤。会员卡不是付费订阅、支付卡或场馆核销凭证，不会自动续费。

<Callout type="warn" title="截图中的测试数据">
本页截图来自 App 的界面测试环境，卡面显示「测试卡」，卡号为样例。正式会员卡显示你的会员状态和卡号。
</Callout>

## 领取会员卡

领卡前，你需要一个已验证邮箱的账号。注册方法见[账号](/docs/guide/account/#注册账号)。

<Screenshots
  shots={[
    { name: "enroll-name", alt: "领卡第 1 步：填写卡面昵称，下方是卡面预览", caption: "1. 写下昵称" },
    { name: "enroll-pledges", alt: "领卡第 2 步：逐条确认三条俱乐部守则", caption: "2. 确认守则" },
    { name: "enroll-review", alt: "领卡第 3 步：核对昵称和邮箱，同意守则与数据说明", caption: "3. 核对并领取" },
  ]}
/>

<Steps>
  <Step>
    打开「我的会员卡」，点「领取免费身份卡」。
  </Step>
  <Step>
    **写下昵称**：填写卡面昵称，1～24 个字符。页面会显示卡面预览。
  </Step>
  <Step>
    **确认守则**：逐条确认三条俱乐部守则：人人都有位置、尊重自己的节奏、尊重他人与隐私。
  </Step>
  <Step>
    **核对并领取**：核对昵称和邮箱，打开「我已阅读并同意守则与数据说明」，点「确认免费领卡」。
  </Step>
</Steps>

领卡后，卡面昵称暂时不能修改。领卡需要联网。

## 查看会员卡

<ShotWithText name="membership" alt="我的会员卡页：卡面、会员状态、出示会员码、制作会员分享卡和身份详情" caption="我的会员卡">

「我的会员卡」显示卡面、会员状态和上次同步的时间。点刷新按钮，可以从服务器重新读取会员状态。

展开「身份详情」，可以查看完整卡号、入会日期和有效期，并复制完整卡号。

| 状态 | 含义 |
| --- | --- |
| 已加入俱乐部 | 会员卡有效 |
| 离线副本 | 设备离线，显示上次同步的结果 |
| 会员卡已暂停 | 会员卡暂时不可用 |
| 会员卡已到期 | 会员卡超过有效期 |
| 会员卡当前不可用 | 其他原因导致会员卡不可用 |

会员状态以服务器为准。离线时，App 显示上次同步的副本。

</ShotWithText>

## 制作分享卡

<ShotWithText name="share-card" alt="分享预览：松林配色的会员纪念卡，卡号已隐藏，下方是配色选择和显示完整卡号开关" caption="分享预览">

<Steps>
  <Step>
    在「我的会员卡」中点「制作会员分享卡」。
  </Step>
  <Step>
    在「分享卡配色」中选择「松林」「月白」或「曜石」。配色只改变图片，不改变会员身份。
  </Step>
  <Step>
    选择是否打开「在图片中显示完整卡号」。默认隐藏卡号，图片仍包含昵称和入会日期。
  </Step>
  <Step>
    点「分享图片」，通过系统分享面板发送。
  </Step>
</Steps>

分享卡只是纪念图片，不能作为会员凭证。

</ShotWithText>

## 添加到 Apple 钱包

<ShotWithText name="app:wallet" alt="Apple 钱包中的薄肌会员卡：深绿色卡面，显示会员卡号、昵称、入会日期、学校和会员码二维码" caption="钱包中的会员卡（样例）">

服务开放后，iPhone 用户可以把会员卡添加到 Apple 钱包：

<Steps>
  <Step>
    在「我的会员卡」中点「添加到 Apple 钱包」。
  </Step>
  <Step>
    在系统窗口中确认添加。
  </Step>
</Steps>

会员状态变化后，钱包中的卡会自动更新。钱包卡只展示身份，不是支付或核销凭证。服务尚未开放时，页面显示「Apple 钱包暂不可用」。

样例中的学校一栏要等[学校认证](/docs/guide/school-ranking/)上线后才会显示。

Android 版暂不支持添加到 Google 钱包。

</ShotWithText>

## 出示会员码

<ShotWithText name="membership-code" alt="会员码页：动态二维码、更新倒计时和会员卡号" caption="会员码">

会员码是一个动态二维码，供工作人员确认你的会员身份。服务开放后，有效的会员卡会显示「出示会员码」按钮。

<Steps>
  <Step>
    点「出示会员码」。
  </Step>
  <Step>
    把二维码出示给工作人员扫描。
  </Step>
</Steps>

二维码每 30 秒更新一次，截图无法使用。添加到 Apple 钱包的会员卡也带有二维码。钱包中的二维码不会变化，工作人员会另外核对本人。

</ShotWithText>

## 工作人员校验会员码

有校验权限的工作人员账号会在「我的会员卡」中看到「扫码校验会员」。工作人员不需要持有会员卡。

<Steps>
  <Step>
    点「扫码校验会员」，允许 App 使用相机。
  </Step>
  <Step>
    把会员出示的二维码放进取景框。无法使用相机时，点「手动输入会员码」，然后点「校验」。
  </Step>
  <Step>
    核对结果中的会员卡号、昵称和状态。如果结果显示二维码来自钱包会员卡，核对出示者是否本人。
  </Step>
</Steps>

相机画面只在本机识别，不会上传。校验需要在 12 小时内登录过的账号。超过 12 小时，退出后重新登录。

## 会员权益

会员卡目前包含日常记录、基础训练库和成长足迹。这些功能不登录也可以使用。付费会员尚未开放，App 不会收取费用。
