今天页显示三件事是否已经记录：**训练**、**饮水**和**睡眠**。三件事都没有必须完成的指标，记录只是为了看见自己的节奏。

<Screenshot name="app:today" alt="今天页：顶部是三项打卡状态，下方是好好喝水、好好睡觉两张卡片和今日推荐课程" caption="今天页" />

## 查看当天进度

今天页顶部的卡片显示三项的状态和完成数，例如 2/3。每一项按以下条件算作已记录：

| 项目 | 已记录的条件 |
| --- | --- |
| 训练 | 当天完成了至少一套课程 |
| 饮水 | 当天的饮水量大于 0 |
| 睡眠 | 当天保存过睡眠时长 |

训练只能通过完成课程来记录，不能手动添加。跟练方法见[课程与跟练](/docs/guide/training/)。

## 记录饮水和睡眠

  shots={[
    { name: "water", alt: "记录饮水窗口：显示 250 mL，下方有 150、250、500 mL 三个快捷按钮", caption: "记录饮水" },
    { name: "sleep", alt: "记录睡眠窗口：显示 8.0 小时，下方是 0 到 16 小时的滑块", caption: "记录睡眠" },
  ]}
/>

<Tabs items={["饮水", "睡眠"]}>
  <Tab value="饮水">
    <Steps>
      <Step>
        在今天页点「好好喝水」。
      </Step>
      <Step>
        选择 150 mL、250 mL 或 500 mL，或者用加减按钮调整。每次可以记录 50～1000 mL，默认 250 mL。
      </Step>
      <Step>
        点「保存」。这次的量会加到当天的总量上。
      </Step>
    </Steps>

    喝一次记一次即可。当天的总量最多为 20,000 mL。

  </Tab>
  <Tab value="睡眠">
    <Steps>
      <Step>
        在今天页点「好好睡觉」。
      </Step>
      <Step>
        拖动滑块选择昨晚的睡眠时长，范围为 0～16 小时，每格 0.5 小时。
      </Step>
      <Step>
        点「保存」。
      </Step>
    </Steps>

    睡眠只记录时长，不记录入睡和起床时间。每天只保存一个值，再次保存会替换当天的值。睡眠时长是你的主观记录，不是设备测量。

  </Tab>
</Tabs>

<Callout title="记错了饮水怎么办">
当天已有饮水记录时，「记录饮水」窗口底部显示红色的撤回按钮：

- **iOS**：「从今天减去 *n* mL」清空当天的全部饮水量。
- **Android**：「撤回 250 mL」从当天的总量中减去 250 mL。
</Callout>

要读取手表或其他 App 测量的睡眠，见[健康数据](/docs/guide/health/)。

## 今日推荐

今天页底部推荐一套课程。推荐的课程由训练场景决定：

| 训练场景 | 推荐课程 |
| --- | --- |
| 居家训练 | 居家基础训练 |
| 健身房训练 | 器械基础训练 |

点推荐卡片可以打开课程。更换场景的方法见[开始使用](/docs/guide/getting-started/#选择训练场景)。
