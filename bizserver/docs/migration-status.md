## 上线前提

迁移命令在独立的 PostgreSQL 数据库中建表，不读取或转换旧服务的数据。PostgreSQL 在事务中执行每个迁移。如果同名的表或索引已经存在，这个迁移会失败并回滚全部改动。

服务启动前会只读检查迁移版本。未初始化的库和版本不符的库都会被拒绝。启动检查不会自行创建迁移登记表。

当前程序拒绝以 `APP_ENV=production` 启动。移除这个保护前，必须完成以下步骤：

1. 完成未迁入功能与安全控制。
2. 让原生客户端通过 ConnectRPC 联调。
3. 演练备份恢复。

Docker 配置仅用于独立开发环境。
