# 会员卡体验完善

本轮完善免费身份卡的领取、展示和分享。版本为 `0.6.0 (6)`。客户端继续使用旧服务契约，没有切换到 Rust 后端。

## 领取

领卡分成三个步骤：填写昵称、逐条确认守则、核对信息并同意数据说明。昵称、守则确认和数据同意都通过校验后，才提交请求。

预览只显示昵称与占位说明，不生成卡号或入会日期。服务器返回后，成功页展示真实响应。关闭表单会丢弃本轮草稿，再次打开需要重新确认。

服务器仍只接收昵称和 `community-v1`。客户端没有增加协议字段，也不把逐条操作冒充服务器审计记录。网络中断时，用户可以先刷新会员信息，再决定是否重试。

## 会员中心

中心区分有效、离线副本、暂停、到期和不可识别的状态。恢复缓存或重试刷新时，旧卡不会提前变成已核验状态。

卡号始终作为不透明字符串展示。「身份详情」支持查看和复制完整卡号。客户端不补号、不截断数据，也不从卡号推断权益。

暂停或不可识别的卡不提供分享和 Wallet 入口。基础训练与本地记录不受影响。权益展示继续使用服务器对象，不把旧字符串缓存当成已确认授权。

## 分享

分享预览提供松林、月白、曜石三种配色。配色仅改变本次图片，不改变等级或权益。卡号默认隐藏，用户可以主动开启完整卡号展示。

图片包含昵称、入会日期、生成日期和凭证边界说明。离线卡与测试卡分别带标记。图片不包含邮箱、内部用户 ID、令牌、权益原始对象或身体数据。

页面展示实际导出图片，使用系统分享面板。打开预览不会自动上传图片。账号或会员卡失效时，预览会关闭；刷新期间暂不提供导出按钮。

## 视觉与辅助功能

卡面使用实色渐变，不使用玻璃材质。Liquid Glass 仅用于系统导航和操作按钮。卡号可以换行，文字布局不依赖固定卡片高度。

表单有进度、返回和取消操作。没有持续旋转或翻转动画。界面保留 Dynamic Type，并为状态、按钮和分享预览提供辅助功能标识。
