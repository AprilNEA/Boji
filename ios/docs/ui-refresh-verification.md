# 界面改造验证记录

本轮按 Apple Human Interface Guidelines 和 Liquid Glass 适配指南改造了 iOS 全部界面。123 项测试全部通过，包括 107 项单元测试和 16 项界面测试。设计规则见[界面设计](design.md)。

验证时间：2026 年 10 月 20 日，UTC+08:00。环境为 Xcode 27.1、iOS 26.5 模拟器（iPhone 17 和 iPhone 17 Pro）。

## 改动范围

| 范围 | 改动 |
| --- | --- |
| 设计系统 | 新增 `PageScroll`、`GroupedRows`、`CardButton`、`AdaptiveStack` 等组件；颜色增加高对比度变体和 `accentFill`；卡片圆角统一为 24 pt |
| 导航 | 标签页使用系统大标题和副标题；标签栏向下滚动时收起，iPad 可切换为侧边栏；每个标签页右上角统一为账户按钮 |
| 功能层 | 主要操作移入 `safeAreaBar` 浮动底栏；弹窗按钮改用 `cancel`、`close`、`confirm` 角色；训练进行页的控制按钮放入 `GlassEffectContainer` |
| 内容层 | 课程、文章、权益和账号改为分组列表；内容卡片中的按钮不再使用玻璃；设置、健康和登录页统一使用品牌背景 |
| HIG 违规 | 移除仿 Activity rings 的同心圆环；固定字号改为语义字号；会员卡面字号设上限 |
| 动效 | 课程、文章和会员卡使用缩放转场；计数和倒计时使用数字过渡；完成一组和完成训练提供触感反馈 |
| 动作动画 | 欢迎页和课程卡使用 Lottie 动作动画，替代原 SF Symbol 椭圆图案 |
| 小组件与手表 | 小组件使用系统边距和强调色渲染；手表使用系统导航标题和工具栏刷新按钮 |
| 工程 | 开发语言改为 `zh-Hans`，系统组件的日期按中文显示 |

## 已验证

| 检查 | 结果 |
| --- | --- |
| 单元测试 | 107 项通过，0 项失败 |
| 界面测试 | 16 项通过，0 项失败 |
| watchOS 构建 | 通过 |
| 浅色与深色截图 | 今天、训练、课程详情、训练进行、休息、完成、足迹、俱乐部、设置、会员各页已人工检查 |

测试结果保存在仓库根目录的 `.work/boji-ios/ui-review/`，截图从 `.xcresult` 导出到同目录的 `shots-*`。

## 修复记录

- 分享页的「显示完整卡号」开关位于浮动底栏下方，界面测试点按时被底栏遮挡。开关和说明已移到预览图上方。
- 辅助功能字号下，浮动主按钮占据半屏。`PrimaryButton` 和 `CardButton` 的字号上限设为 `accessibility2`。
- 深色模式下，白字在亮橙色按钮上的对比度为 2.58:1。白色文字下的填充色改用 `accentFill`。
- 导航栏副标题不读取 SwiftUI 的语言环境，日期显示为英文。日期改为预先按当前语言格式化，工程开发语言改为 `zh-Hans`。

- iPad 侧边栏布局和横屏。
- VoiceOver 完整操作流程、「减弱透明度」和「增强对比度」系统设置下的实际效果。
- 小组件在主屏幕的着色和透明外观。
