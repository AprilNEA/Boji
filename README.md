## 薄肌理论

- **薄肌**：穿衣显瘦，脱衣有肉。体脂长期保持在 13% 以下，不吃欺骗餐。
- **黄毛**：不被外界评价左右，坚持自己判断过的方向。
- **大水**：成年男性每天喝 1700 mL 水，成年女性每天 1500 mL 起。
- **大睡**：每晚睡 7 小时～9 小时，不靠周末补觉。

## 功能

- Boji 把薄肌理论拆成每天三项打卡：训练、饮水和睡眠。

每个课程动作都有一段循环播放的 Lottie 动画。动画用颜色标出主要发力的肌群，并有浅色和深色两套。

系统开启「减少动态效果」或关闭动画时，App 显示动作的代表姿势，例如深蹲的最低点。动作说明还列出组数、次数、要点和主要肌群。

### 俱乐部与会员卡

俱乐部页有每周挑战和 3 篇入门文章，主题是训练、饮食和休息。每周挑战只在本机计算。登录已验证的邮箱账号并确认俱乐部守则后，可以领取免费会员卡。分享会员卡图片时，可以从三种配色中选一种，卡号默认隐藏。

会员卡依赖后端 `bizserver/`，后端目前尚未部署。

### 本地数据

训练、打卡和足迹的记录保存在手机上，不需要账号。设置页可以把全部记录导出为 JSON，也可以删除全部本地数据。只有领取会员卡时才需要登录。

### 平台差异

两端的课程、打卡、足迹、俱乐部和会员卡功能相同。系统集成按平台分别实现：

| 功能 | iOS | Android |
| --- | --- | --- |
| 健康数据（只读） | Apple 健康：体重、腰围和睡眠 | Health Connect：体重和睡眠 |
| 小组件 | 主屏幕和锁定屏幕 | 主屏幕 |
| 手表 | Apple Watch | Wear OS |
| 系统账号登录 | Apple 登录，服务端开放后可用 | 尚未支持 |
| 钱包会员卡 | Apple Wallet，服务端开放后可用 | 尚未支持 |

Android 版的移植情况见 [Android 说明](android/README.md#尚未移植的功能)。各端的无障碍支持情况见[无障碍说明](docs/ACCESSIBILITY.md)。

课程和动作动画是通用参考，不提供医疗诊断。
