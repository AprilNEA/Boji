# 薄肌俱乐部 · 实现计划（Next.js 版）

## 目标

做一个“完全苹果味”的多页面粉丝向恶搞网站。视觉和交互对标 apple.com 与苹果发布会，内容沿用已确认的设计草案（`/home/ubuntu/thin-muscle-club/薄肌俱乐部-设计草案.md`）。用 Next.js 开发，不做单页；用 React 动画库实现丝滑的滚动与过渡动效。

## 技术方案

| 层 | 选型 | 用途 |
| --- | --- | --- |
| 框架 | Next.js 16（App Router）+ TypeScript | 多路由页面，`output: "export"` 静态导出 |
| 样式 | Tailwind CSS 4 + CSS 变量 | 苹果设计 token、响应式布局 |
| 动画 | Motion（原 Framer Motion）14 | 入场、滚动联动（`useScroll` / `useTransform`）、粘性滚动叙事、页面切换、共享布局动画、弹层 |
| 平滑滚动 | Lenis | 苹果官网那种带惯性的顺滑滚动，并与 Motion 的滚动进度同步 |
| 字体 | Inter Variable（自托管，`@fontsource-variable/inter`）+ 系统苹方 / Noto Sans SC | 可变字重，用于“Think Thin.”由粗变细等字重动画 |
| 会员卡导出 | `html-to-image` | 把生成的会员卡保存为 PNG |

整站是纯静态站点，不需要服务器和数据库。会员卡、计算器等交互都在浏览器端完成。发布时执行静态构建，产物目录为 `out/`。

## 页面与路由

导航栏的六个入口各对应一个独立页面，首页是发布会主舞台。

| 路由 | 页面 | 主要内容与动效 |
| --- | --- | --- |
| `/` | 发布会首页 | 第 1 屏创始人 Hero（“Think Thin.”加载时字重 900→200，人像依次淡入，悬停显示语录卡片）；第 2 屏薄肌 Pro 揭幕（鸡胸肉随滚动浮起、旋转，四个参数滚动计数）；第 3 屏 M13 意志力芯片（滚动时绿色电路光线汇聚点亮芯片）；第 4 屏薄肌 Intelligence（三张 iOS 通知卡依次弹出）；第 5 屏对比入口；第 7 屏 One more thing（剪影 + 体脂进度条） |
| `/theory` | 理论 | 致敬苹果“隐私/环保”宣言页：逐字随滚动高亮的长句宣言；四个原则（薄肌、黄毛、大水、大睡）用粘性滚动依次切换 |
| `/pro` | 薄肌 Pro 产品页 | 产品大图揭幕、亮点卡片横向滑动（苹果“了解亮点”轮播）、芯片段落、Apple 风“技术规格”表 |
| `/compare` | 对比 | 苹果机型对比页：厚肌 / 饿瘦 / 薄肌 Pro 三栏，每栏顶部可切换型号的下拉菜单，切换时数值淡入淡出 |
| `/calculator` | 计算器 | 仿 Apple Store 购买配置流程：选择当前体脂、每周训练次数、含糖饮料频率，右侧实时生成“预计交付日期”和订单摘要 |
| `/founders` | 创始人 | 仿苹果 Leadership 页：两位人像网格，点击展开个人简介弹层（共享布局动画放大），第三格是“下一位践行者：你”的入会入口 |
| `/join` | 入会 | 三档会员方案卡片（均 ¥0/月，“代价：含糖饮料。”）→ 宣誓页（全部勾选后“庄严入会”才亮起）→ 生成 Apple Card 风会员卡（随鼠标 3D 倾斜、可输入姓名、可保存为 PNG） |
| 404 | 未找到 | “该页面体脂超标，已被移除。” |

全站组件：毛玻璃导航栏（滚动后加深，移动端展开为全屏菜单）、购物袋弹层（“您的购物袋是空的。薄肌无法购买。”）、Cookie 提示（“本站不使用 Cookie。含糖量过高。”）、首次加载“正在燃脂…”、页面切换淡入淡出、按钮悬停时描边和字重同时变细、苹果式编号免责页脚（含“未获授权或背书”声明与“保留所有线条”）。

## 图片素材

- **两位人像**：使用两位本人的公开照片，统一做黑白、提高对比度并加暗角，融入黑色背景；不用 AI 生成的仿像。页脚保留“与本人无关联、未获授权或背书”的声明。
- **需要生成的素材**（无文字的干净素材）：鸡胸肉产品图（透明背景）、M13 芯片渲染图、One more thing 舞台剪影、理论页黑白训练氛围图、薄肌 Pro 亮点卡片用的几张产品/生活方式图。
- **自己绘制的 SVG**：西兰花 Logo、对比页三种体型剪影、导航图标。

## 设计系统

沿用设计草案中已确认的苹果发布会风，不再另选风格。

- **设计流派**：apple.com 产品页 + 苹果秋季发布会舞台。
- **核心原则**：视觉零妥协；文案用苹果腔；网站自己不笑场；一屏只讲一件事。
- **色彩**：发布会黑 #000000 与铝灰白 #F5F5F7 交替成屏；正文墨 #1D1D1F，次级灰 #86868B；链接蓝 #0071E3 / #2997FF；唯一品牌色是西兰花绿渐变 #A8E063 → #2F7D32，只用在“薄肌 Pro”字样和关键数字上；“全新”角标用新品橙 #F56300。
- **版式**：黑白屏交替的长卷叙事，大量粘性滚动段落，不用平均分布的卡片网格作为主结构；文字区最大宽 980 px，图片全出血。
- **标志性元素**：会变细的标题字重；西兰花剪影 Logo；苹果式编号脚注小字。
- **交互**：所有按钮和链接悬停时变细，而不是变粗或变色；弹层和面板全部用弹簧曲线。
- **动画**：入场用 0.8–1.2 秒的 ease-out（`[0.16, 1, 0.3, 1]`）位移 + 透明度；滚动联动动画全部绑定滚动进度，不用定时触发；尊重系统“减少动态效果”设置。
- **字体**：拉丁文与数字用 SF Pro（苹果设备）/ Inter Variable；中文用苹方 / Noto Sans SC；标题 700、字距 -0.03em，数字用等宽数字。
- **品牌定位**：给想“把人生控制权拿回来”的年轻人的薄肌发布会，一本正经地搞笑；形容词：克制、精确、荒诞。
- **品牌语气**：短句、句号、苹果式夸张。例：“Pro 级线条。非 Pro 级体积。”“鸡胸肉，从未如此 Pro。”
- **Logo**：极简西兰花剪影，单色，作用等同苹果的那只苹果。
